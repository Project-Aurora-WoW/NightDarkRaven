# Гибридная архитектура: C++ ядро + Lua контент

Ночь темного Ворона использует гибридный подход: производительные системы в C++, контент в Lua.

## Что где выполняется

### C++ (ядро, требует перекомпиляции)

| Функция | Файл | Постоянство |
|---------|------|-------------|
| Навыки игрока | `Player.cpp/h` | `character_skills` (БД) |
| Соло-модификаторы урона | `Unit.cpp/h` | В памяти + `solo_state` |
| Соло-модификаторы здоровья | `Unit.cpp/h` | В памяти + `solo_state` |
| Загрузка при входе | `WorldServer.cpp` | Из БД при логине |

### Lua (Eluna, без перекомпиляции)

| Функция | Файл | Постоянство |
|---------|------|-------------|
| Квесты кампаний | `quest_system.lua` | `quest_template` (БД) |
| Gossip-меню NPC | `quest_system.lua` | В памяти |
| Лут мобов | `05_campaigns_loot.sql` | `creature_loot_template` |
| Спавны мобов | `06_campaigns_spawns.sql` | `creature` |
| События мира | `world_events.lua` | В памяти |
| Патчи клиента | `client_patch_system.lua` | `client_patches` |

## Пример взаимодействия

**Игрок включает соло-режим:**
1. Lua (`solo_system.lua`) вызывает `SoloEnable()`
2. C++ мост вызывает `Player::SetSoloModeEnabled(true)`
3. C++ сохраняет в `solo_state` (БД)
4. При следующем входе `WorldServer.cpp` загружает `solo_state` и применяет модификаторы

**Игрок приручает моба:**
1. Lua (`companion_system.lua`) вызывает `AttemptTame()`
2. Lua проверяет навык через `HasNightRavenSkill(90005)`
3. C++ проверяет в `m_nightRavenSkills` (память) или `character_skills` (БД)
4. При успехе Lua спавнит компаньона через `SpawnCreature()`

## Преимущества гибридного подхода

| Аспект | C++ ядро | Lua контент |
|--------|----------|-------------|
| Производительность | ✅ Высокая | ⚠️ Средняя |
| Постоянное хранение | ✅ БД | ⚠️ Виртуальная память |
| Перекомпиляция | ❌ Требуется | ✅ Не требуется |
| Быстрая итерация контента | ❌ Медленно | ✅ Быстро |
| Контроль над игровым движком | ✅ Полный | ⚠️ Ограничен API |

## Рекомендация по разработке

1. **Контент (квесты, мобы, предметы, диалоги)** — держите в Lua, меняйте без пересборки
2. **Системные механики (навыки, соло-режим, модификаторы)** — в C++, меняйте редко
3. **Веб-интерфейс** — отдельный Node.js сервер, общается через БД и API
