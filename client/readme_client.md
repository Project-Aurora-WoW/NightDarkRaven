# Клиент WoW 3.3.5a — Ночь темного Ворона

В этом репозитории **не хранится сам клиент** WoW (авторские права Blizzard Entertainment).

## Что нужно сделать вручную

1. Установите клиент World of Warcraft 3.3.5a (build 12340).
2. Если нужна кастомная локализация/интерфейс — положите патчи в `client/patches/` и соберите `patch.MPQ`/`patch-enUS.MPQ` по стандарту Cascada/MPQ 3.3.5a.
3. Настройте `realmlist.wtf` (см. `client/configs/realmlist.wtf`):
   - Локальный сервер: `set realmlist 127.0.0.1`
   - Удалённый сервер: `set realmlist logon.nightdarkraven.ru`
4. Запустите `WoW.exe` (или лаунчер) и подключитесь к реальму AzerothCore.

## Состав клиентской части (планируется)
- `realmlist.wtf` — адрес сервера входа
- `patch.MPQ` — кастомные текстуры/модели под лор "Ночь темного Ворона"
- `WTF/` — конфигурационные переменные клиента

## Примечание по AzerothCore + 3.3.5a
AzerothCore (ветка wotlk) полностью совместим с протоколом клиента 3.3.5a. Все серверные изменения (новые мобы, квесты, спеллы) должны быть синхронизированы с клиентскими данными, иначе клиент может отображать элементы некорректно.
