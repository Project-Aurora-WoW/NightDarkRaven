# Кастомные MPQ ресурсы клиента WoW 3.3.5a

Папка содержит инструменты, шаблоны и инструкции для создания кастомных моделей и текстур для клиента WoW 3.3.5a проекта «Ночь темного Ворона».

## ⚠️ Важное предупреждение

**Сам клиент World of Warcraft 3.3.5a и его оригинальные ресурсы НЕ входят в этот репозиторий.** Они принадлежат Blizzard Entertainment. Вы должны обладать лицензионной копией клиента WoW 3.3.5a для использования этих инструментов.

Все файлы в этой папке — это **шаблоны и инструкции** для создания собственных ресурсов на основе вашего установленного клиента.

## Структура

```
client/custom_content/
├── models/          # Кастомные 3D модели (.mdl, .m2)
├── textures/        # Кастомные текстуры (.blp)
├── mpq/             # Сборка MPQ архива клиента
├── tools/           # Инструменты конвертации
└── client_config.md # Настройка клиента для загрузки кастомных MPQ
```

## Быстрый старт

1. Установите клиент WoW 3.3.5a (build 12340)
2. Создайте кастомные модели и текстуры (см. инструкции ниже)
3. Соберите их в `patch.MPQ` с помощью скриптов в папке `mpq/`
4. Положите `patch.MPQ` в папку с клиентом WoW (рядом с `WoW.exe`)
5. Запустите клиент — кастомные ресурсы загрузятся автоматически

## Как работает загрузка кастомных ресурсов

Клиент WoW 3.3.5a загружает MPQ архивы в следующем порядке:
1. `patch.MPQ` — кастомные ресурсы (самый высокий приоритет)
2. `patch-enUS.MPQ` — локализация
3. `enUS.MPQ` — основные ресурсы
4. И другие базовые MPQ

Файлы в `patch.MPQ` перекрывают файлы из базовых архивов, что позволяет заменить модели, текстуры, звуки и интерфейс.

## Связь с сервером AzerothCore

Для того чтобы новые модели появились в игре, необходимо:
1. Добавить запись в `creature_template` с правильным `displayid`
2. Указать `displayid` соответствующей кастомной модели в клиенте
3. Собрать модель с тем же `displayid`, что указан в базе данных

Пример SQL для кастомного NPC с кастомной моделью:
```sql
INSERT INTO `creature_template` (`entry`, `name`, `modelid_1`, `faction`, `npcflag`) VALUES
(92001, 'Кастомный Ворон', 25001, 35, 1);
```

Где `25001` — это `displayid` вашей кастомной модели в клиенте.
