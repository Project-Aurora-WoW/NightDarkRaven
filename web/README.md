# Веб-клиент «Ночь темного Ворона»

Веб-интерфейс для MMORPG на базе AzerothCore + WoW 3.3.5a. Позволяет:
- авторизоваться через аккаунт AzerothCore (БД `auth`);
- просматривать список персонажей (БД `characters`);
- управлять соло-режимом, компаньонами, квестами кампаний;
- просматривать карту мира, зоны, подземелья;
- общаться с сервером через REST API.

## Структура

```
web/
├── README.md
├── package.json              # Node.js зависимости
├── server/
│   ├── index.js              # Express сервер
│   ├── config.js             # Конфигурация БД и порта
│   └── routes/
│       ├── auth.js           # Авторизация (логин/пароль аккаунта)
│       ├── characters.js     # Персонажи (список, информация)
│       ├── world.js          # Мир (зоны, кампании, подземелья)
│       └── solo.js           # Соло-режим и компаньоны
└── client/
    ├── index.html            # Главная страница веб-клиента
    ├── css/
    │   └── style.css         # Стили (фэнтези-оформление)
    └── js/
        ├── api.js            # Вызовы к REST API
        └── app.js            # Логика интерфейса
```

## Быстрый старт

```bash
cd web
npm install
cp config.example.json config.json
# Отредактировать config.json: указать пароли к MySQL (auth/characters/world)
npm start
```

Веб-клиент будет доступен на `http://localhost:3000`.

## Подключение к AzerothCore

Веб-сервер подключается напрямую к MySQL базам AzerothCore:
- `auth` — аккаунты, реалмы, аутентификация
- `characters` — персонажи, квесты, инвентарь
- `world` — шаблоны мобов, предметов, квестов (только для чтения)

Требуется MySQL 5.7+/MariaDB 10.3+ и Node.js 16+.

## Безопасность

В проде обязательно:
- использовать HTTPS (TLS);
- сменить пароли в `config.json`;
- ограничить доступ к API по IP или через токены;
- не хранить `config.json` в публичном репозитории (добавлен в `.gitignore`).
